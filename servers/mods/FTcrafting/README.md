# FTcrafting

Дополнительный мод рецептов для FTCRAFT.

## Требования

- Minecraft 1.21.1
- NeoForge 21.1.235
- Java 21
- FTCRAFT 0.1.0+

## Первая тестовая версия

Добавляет предметы и рецепты T1 для палки, тростника, глины, пера, кожи, пороха, сахара, нити, каменной плиты, деревянной плиты и изысканной слизи.
