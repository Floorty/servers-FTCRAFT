# FTCRAFT Resource Packs

Общая папка исходных ресурсов для модов FTCRAFT.

## Структура

- `FTCRAFT/` — ресурсы главного мода
- `FTcrafting/` — текстуры и модели предметов системы крафта
- `FTcoins/` — ресурсы валюты и магазина
- `FTchat_tab/` — интерфейс, чат, TAB и HUD
- `shared/` — общие ресурсы нескольких модов

Исходные изображения и проекты хранятся здесь. Готовые игровые файлы копируются в
`src/main/resources/assets/<mod_id>/` соответствующего мода.
